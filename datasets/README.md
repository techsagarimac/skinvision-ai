# Datasets

Keep training images and labels here in YOLO directory format.

Recommended layout:

```
datasets/
  images/train
  images/val
  images/test
  labels/train
  labels/val
  labels/test
  data.yaml
```

Only store data you have rights to use. Prefer documented licenses, consent,
and diverse capture conditions (lighting, skin tone, camera, angle, distance).
