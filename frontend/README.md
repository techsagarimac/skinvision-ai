# SkinVision AI frontend

Next.js App Router interface for capture, analysis review, history, and privacy.

## Setup

```bash
cd frontend
npm install
cp .env.example .env.local
npm run dev
```

Open `http://localhost:3000`.

`NEXT_PUBLIC_API_URL` must point at the FastAPI server.

## Scripts

```bash
npm run dev
npm run typecheck
npm run lint
npm run build
```
